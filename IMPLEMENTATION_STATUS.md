# Состояние реализации

Статусы: `готово`, `частично`, `не реализовано`, `отложено`.

| Область | Статус на начало системной переработки | Следующее действие |
|---|---|---|
| Telegram-бот и подключение | готово | Упростить пользовательский сценарий |
| Регистрация без кодов | частично | Убрать обязательные коды и создавать запись в общем пуле |
| RU/KZ | частично | Проверить все новые и существующие сообщения |
| Участники | частично | Улучшить массовые действия и редактирование |
| Команды | частично | Довести управление составом и удаление |
| Рассылка составов и загадок | готово | Сохранить раздельными действиями и проверить переводы |
| Telegram-беседы | отложено | Убрать из обязательного сценария |
| Выбор капитана | частично | Привести к личному боту и обработать ничью/смену |
| Выбор отвечающего | частично | Добавить единый сценарий с подтверждением ответа |
| Редактор текстовых вопросов | частично | Разделить на фиксированные блоки и улучшить UX |
| Редактор выбора варианта | частично | Сделать варианты отдельными редактируемыми строками |
| Фиксированная программа | не реализовано | Убрать универсальное создание игр и этапов |
| Тестовый вопрос без баллов | не реализовано | Добавить специальный режим и сброс |
| Большой экран | частично | Превратить в управляемую презентацию |
| Клавиатурная навигация | не реализовано | Добавить `←` и `→` |
| Редактор слайдов | не реализовано | Добавить информационные и автоматические слайды |
| Таймер обсуждения | частично | Добавить паузу, сброс и безопасное управление |
| Таймер ответа | частично | Отделить от обсуждения и связать с ботом капитана |
| Сброс ответов | не реализовано | Добавить общий и командный сброс |
| Ручная проверка | готово | Улучшить массовую работу и частичные баллы |
| Анонимные версии | готово | Связать с презентационным сценарием |
| Общий детективный кейс | не реализовано | Переделать текущие отдельные кейсы после ревизии улик |
| Масштабирование улик | готово частично | Повторно проверить для общего кейса и составов 8–10 |
| Дополнительные баллы | готово | Улучшить категории, детализацию и отмену |
| Сообщения | частично | Проверить медиа, получателей и скрытие лишних полей |
| Журнал | готово | Добавить новые переходы, сбросы и паузы |
| Docker/ngrok | готово | Сохранить локальный вариант запуска |
| Постоянный хостинг | отложено | Выбирает организатор отдельно |
| Автотесты | частично | Добавить проверки новых бизнес-правил |
