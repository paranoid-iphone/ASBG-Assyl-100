# Платформа управления интеллектуальными ивентами

Многоразовый инструмент для организаторов: ивенты, команды, игроки, вопросы, ответы,
баллы, Telegram-бот и отдельный большой экран.

## Структура продукта

### Главное меню

`/admin` показывает все созданные ивенты. Здесь можно создать новый ивент или открыть
существующий. Данные разных ивентов изолированы друг от друга.

### Панель ивента

`/admin/events/{id}` содержит:

- обзор;
- проведение игры;
- этапы и вопросы;
- детективная гонка;
- команды и игроков;
- ответы участников;
- баллы и рейтинг;
- журнал действий.

### Сбор команд и выбор капитана

В карточке команды организатор хранит загадку названия на двух языках, ссылку на
Telegram-беседу и её chat ID. Отдельными кнопками можно разослать каждому участнику
список сокомандников с загадкой, затем отправить ссылку на беседу и запустить внутри
неё голосование за капитана. Название команды участники сообщают ведущему устно — бот
его не принимает и не проверяет.

### Сдача командных ответов

Обычный вопрос проходит через пять экранов: вопрос, таймер обсуждения, отдельное окно
отправки капитаном, правильный ответ и анонимные версии команд. После окончания окна
ответы не принимаются, а уже отправленный ответ нельзя изменить. Капитан отмечает
участника, сформулировавшего версию. Поддерживаются свободный текст, выбор варианта и
выбор варианта с кратким объяснением. Все ответы первого и второго этапов проверяются
организатором вручную в админке.

### Детективная гонка

Для каждой активной команды система создаёт отдельный логический кейс. Перед запуском
проверяются единственность решения, отсутствие повторяющихся карточек и необходимость
каждой улики. Генератор учитывает фактический состав каждой команды от 4 до 10 человек:
команды из 8, 9 и 10 участников могут играть одновременно, а каждому активному игроку
назначается ровно одна персональная улика и отправляется в Telegram.

Капитан выбирает ответ из вариантов и отдельно подтверждает его. После подтверждения
ответ изменить нельзя. Правильные команды получают баллы по очередности отправки;
шкала мест настраивается в этапе. На большом экране во время детектива отображаются
только правила, общий таймер и количество ответивших команд.

### Большой экран

Каждый ивент получает непредсказуемую публичную ссылку:

```text
/screen/{token}
```

Её открывают на компьютере, подключённом к проектору, и нажимают `F11`. Страница сама
обновляется автоматически. Оператор управляет показом последовательными кликами:

1. показать первый вопрос;
2. запустить таймер;
3. показать правильный ответ;
4. перейти к следующему вопросу.

Далее цикл повторяется. После ответа на последний вопрос экран возвращается к заставке.
Оператор не имеет доступа к административным данным.

Во время обратного отсчёта вопрос скрывается: на экране остаётся только крупный таймер
по центру. Каждая смена секунды сопровождается коротким тиканьем, последние 10 секунд
звучат заметнее, а при достижении `00:00` воспроизводится гонг. Звук можно отключить в
настройках ивента.

На странице большого экрана есть отдельный регулятор громкости. Выбранный уровень
сохраняется в браузере этого компьютера и не сбрасывается при обновлении страницы.

В настройках задаётся стандартное время на обдумывание. Оно автоматически подставляется
при создании вопроса, но для каждого вопроса можно указать собственное значение.

## Регистрация в Telegram

Организатор задаёт код ивента и код каждой команды. Участник:

1. запускает бота;
2. вводит код ивента;
3. вводит имя и фамилию;
4. вводит код команды.

Игрок создаётся автоматически. Возможность заранее создать игрока и выдать ему
персональный код также сохранена.

Код команды можно не вводить вручную при её создании. Система генерирует латинский slug
из русского или казахского названия, например `Бірлік` → `BIRLIK`. Если такой код уже
есть в ивенте, добавляется суффикс `-2`, `-3` и далее.

При первом запуске участник выбирает `Русский` или `Қазақша`. Выбор сохраняется в
профиле и определяет язык меню и текущего вопроса в боте. Язык можно изменить кнопкой
`Тіл / Язык`.

## Два языка контента

У этапа и вопроса есть отдельные поля RU и KZ:

- название этапа;
- название и текст вопроса;
- правильный ответ;
- пояснение.

В настройках ивента выбирается режим большого экрана:

- русский;
- қазақша;
- оба языка рядом.

Если перевод ещё не заполнен, экран использует доступную версию вместо пустого блока.

## Сообщения

Из раздела «Сообщения» организатор может отправить сообщение:

- всем зарегистрированным участникам ивента, кроме администраторов;
- выбранному участнику;
- в групповой Telegram-чат выбранной команды.

Для отправки в командную беседу бот должен быть добавлен в неё, а у команды должен быть
сохранён `Telegram chat ID`.

## Проверка ответов

Кнопка «Сравнить с эталоном» выполняет строгое автоматическое сравнение с правильным
ответом. Она игнорирует регистр, лишние пробелы, часть пунктуации и различие `ё/е`.
Синонимы и близкие формулировки автоматически не распознаются — их организатор отмечает
вручную.

## Импорт и экспорт контента

На странице «Игры и вопросы» можно скачать или загрузить JSON-файл. Он переносит:

- этапы и их порядок;
- русские и казахские версии;
- вопросы и правильные ответы;
- пояснения;
- время на обдумывание;
- личные и командные баллы;
- настройки приёма ответов.

Импорт добавляет этапы в конец текущего ивента и не удаляет уже созданный контент.

## Локальный запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python -m app.seed
uvicorn app.main:app --reload
```

Админка: `http://127.0.0.1:8000/admin`

Доступ по умолчанию:

- логин `admin`;
- пароль `change-me`.

Локальная база — `game_v9.db`.

## Публикация на Render

Покупать домен не нужно. Render выдаст адрес вида:

```text
https://intellectual-game-platform.onrender.com
```

В проекте есть `render.yaml`, который создаёт веб-сервис и PostgreSQL.

1. Загрузить папку проекта в GitHub.
2. В Render выбрать **New → Blueprint**.
3. Подключить репозиторий.
4. Render прочитает `render.yaml` и создаст приложение с базой.
5. При необходимости задать `TELEGRAM_BOT_TOKEN`.
6. После публикации открыть `/admin`.
7. Пароль найти в настройках переменной `ADMIN_PASSWORD` созданного сервиса.

Для реального мероприятия рекомендуется тариф без засыпания сервиса. Бесплатный сервис
может долго запускаться после простоя.

### Переменные окружения

- `DATABASE_URL` — Render подключает автоматически к PostgreSQL;
- `ADMIN_USERNAME` — логин организатора;
- `ADMIN_PASSWORD` — пароль организатора;
- `SECRET_KEY` — секрет приложения;
- `TELEGRAM_BOT_TOKEN` — необязателен, пока нужен только сайт.
